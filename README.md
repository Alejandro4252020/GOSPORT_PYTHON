# GOSPORT

Sistema web para gestión deportiva y tienda online.

## Funcionalidades
- Reserva de canchas
- Catálogo de productos
- Carrito de compras
- Perfil de usuario

## Tecnologías
- Django
- HTML, CSS, Bootstrap
- JavaScript

## Instalación
1. Clonar repositorio
2. Crear entorno virtual:
   python -m venv venv
3. Activar entorno:
   venv\Scripts\activate
4. Instalar dependencias:
   pip install -r requirements.txt
5. Ejecutar:
   python manage.py runserver
